**AE-370: Dynamical System Numerical Methods Project**

This project investigates the relationship between rocket burn time, initial mass, and maximum altitude (apogee), while maintaining constant total impulse and propellant mass. 
The simulation uses a fourth-order Runge-Kutta (RK4) numerical integration method implemented from scratch.

**Repository Contents**

The repository contains the complete source code, divided into six sections:

1. Parameters
2. Model + RK4 solver 
3. Burn-time sweep 
4. Loss breakdown/analysis
5. Verification 
6. Optimum vs rocket


**How to Run**

download or fork the repository, then download/paste the files in order onto Jupyter notebook to run the code.
